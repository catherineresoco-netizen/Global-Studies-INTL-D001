# Beyond the Frame
A static visual essay, ready for GitHub Pages. No dependencies or build commands.

1. Create a GitHub repository (for example `global-studies-collage`).
2. Upload the contents of this folder to the repository root, keeping the `assets` folder intact.
3. In Settings > Pages, select Deploy from a branch, then `main` and `/ (root)`, and Save.
4. Open the URL GitHub Pages displays after deployment.

Preview locally by opening `index.html`. The full essay is readable without JavaScript; animations respect reduced-motion preferences. The original essay prose and references are retained, with editorial chapter headings and image crops added for the website.
